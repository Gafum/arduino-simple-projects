# Arduino simple projects

This repository contains a few simple Arduino projects that I made during practice at Mercedes. They helped me understand how basic electronic parts, sensors, motors, and simple mechanisms work.

## What this repository is about

Here you can find small Arduino-based projects. They are not too complicated, but they are good for learning the basics of electronics, programming, and working with components.

Some of these projects use an Arduino Mega board because of the RFID reader and stepper motor, while others can work on an Arduino Uno or a similar board.

## Projects

### 1. Remote open close

This project works with an IR remote and a servo motor. By pressing buttons on the remote, you can open and close a simple mechanism.

### 2. Smart motor access

This project uses an RFID reader and a stepper motor. Access is granted only after the correct card is detected.

### 3. TMP36 LCD Display

This project measures temperature with a TMP36 sensor and shows the result on an LCD display.

### 4. Traffic light with sensor

This is a simple traffic light system with an ultrasonic sensor. When an object comes close, the light sequence changes.

## Why this project is useful

This repository is good for beginners who are just starting to learn Arduino. It shows how code, sensors, motors, and other electronic parts can be combined into simple working devices.
